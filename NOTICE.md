# Unofficial prototype

Cube Creatures Web is an unofficial fan/prototype project. It is not affiliated
with or endorsed by CUBE Creatures LLC. Cube Creatures names, card text, artwork,
and other game assets belong to their respective owners.

Game assets must not be redistributed without the owner's permission. This
repository does not include the card image collection. Remote images are loaded
from the configured source; optional local caches are ignored by Git.

No analytics or trackers are included.
